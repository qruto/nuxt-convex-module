Two ready-made apps you can create with `create nuxt`. Both run against a Convex deployment of your own.

## Starter

A minimal Nuxt app with the module installed and one Convex table: a welcome page with a message board that renders on the server and updates live in every open tab. Its look is one stylesheet, `app/assets/css/main.css`, to change or delete.

:pm-create{template="gh:qruto/nuxt-convex-module/templates/starter"}

Then start it with the `dev` script, as described in [Run](/getting-started/installation#run). The app's functions are in `convex/messages.ts`, the board that calls them is `app/components/Messages.vue`, the page is `app/app.vue`, and `convex/_generated` is included so the app type-checks before the first run. [View the source](https://github.com/qruto/nuxt-convex-module/tree/main/templates/starter).

## Example: playground

One page that runs every core feature, one click each, in this site's design: live queries, mutations with optimistic updates, cursor pagination, file storage, actions, and server rendering with `fetchQuery`.

:pm-create{template="gh:qruto/nuxt-convex-module/examples/playground"}

It is also the app behind the **Open in StackBlitz** link on every pull request. [View the source](https://github.com/qruto/nuxt-convex-module/tree/main/examples/playground).
