Six pages take you from an empty Nuxt app to live Convex data, ready to deploy.

- [Introduction](/getting-started/introduction) — what the module is, what it gives you, and where it differs from the Convex React API.
- [Installation](/getting-started/installation) — add the module, set the deployment URLs, run Nuxt and Convex side by side.
- [Configuration](/getting-started/configuration) — module options, runtime config, and the `#convex/*` import aliases.
- [Security](/getting-started/security) — the Convex-aware CSP, the hardened auth proxy, SSR tokens, safe redirects, and a production checklist.
- [Stability](/getting-started/stability) — what 1.0 promises to keep, what is experimental, and how upstream releases map to this module's versions.
- [Troubleshooting](/getting-started/troubleshooting) — every warning and error the module can print, what causes it, and the fix.

From there, the [Guide](/guide/queries) covers the composables one at a time, and [Components](/components) covers the opt-in auth and billing packages.
