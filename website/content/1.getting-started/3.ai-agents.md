Coding agents work best with docs written for them. The module provides three things: a skill your agent installs into the project, an MCP server that serves these docs, and a Markdown version of every page. To install the module itself with an agent, use the prompt at the top of [Installation](/getting-started/installation#with-an-ai-agent).

## Agent skill

The `nuxt-convex-module` skill teaches an agent how to install the module and how to use it. It covers the composables and when to pick each one, server-side rendering, file storage, auth and billing setup on both the Nuxt and the Convex side, and where each topic is documented. Agents load it when a task involves Convex in a Nuxt app.

```bash
npx skills add https://nuxt-convex-module.dev --skill nuxt-convex-module
```

The [skills CLI](https://github.com/vercel-labs/skills) puts it in `.agents/skills/` and links it into your agent's own folder (`.claude/skills/` for Claude Code, for example). It works with Claude Code, Cursor, Codex, GitHub Copilot, Gemini CLI, Windsurf, OpenCode and other agents. `npx skills update` brings it up to date.

The skill covers the Nuxt side. For the backend functions, use Convex's own guidance: its guidelines file, which `npx convex ai-files install` writes to `convex/_generated/ai/` and links from `AGENTS.md` and `CLAUDE.md`, and its skills:

```bash
npx convex ai-files install
npx skills add get-convex/agent-skills
```

## Docs MCP server

These docs are also an MCP server at `https://nuxt-convex-module.dev/mcp`. It gives an agent two tools: `list-pages` to find a page and `get-page` to read it. Add it to your agent:

**Claude Code**

```bash
claude mcp add --transport http nuxt-convex-module https://nuxt-convex-module.dev/mcp
```

**Cursor**: [add to Cursor](https://nuxt-convex-module.dev/mcp/deeplink?ide=cursor).

**VS Code**: [add to VS Code](https://nuxt-convex-module.dev/mcp/deeplink?ide=vscode).

**Codex**

```bash
codex mcp add nuxt-convex-module --url https://nuxt-convex-module.dev/mcp
```

**Any other agent**

```bash
npx add-mcp https://nuxt-convex-module.dev/mcp
```

## Markdown pages

Every page has a Markdown version, which an agent can read without the site's layout:

- [`/llms.txt`](https://nuxt-convex-module.dev/llms.txt) lists every page with a one-line summary.
- [`/llms-full.txt`](https://nuxt-convex-module.dev/llms-full.txt) is every page in one file.
- `/raw/<page>.md` is one page, for example [`/raw/getting-started/installation.md`](https://nuxt-convex-module.dev/raw/getting-started/installation.md).

The menu next to each page's title copies the page as Markdown, opens it in ChatGPT or Claude, or adds the MCP server.
