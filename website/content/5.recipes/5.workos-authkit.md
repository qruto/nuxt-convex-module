WorkOS has no Vue or Nuxt SDK, so the module has no AuthKit adapter. Its framework-free [`@workos-inc/authkit-js`](https://github.com/workos/authkit-js) client and the module's [`provideConvexWithAuth`](/guide/auth-state) do the same job as `@convex-dev/workos`'s React adapter.

Install the client:

:pm-install{packages="@workos-inc/authkit-js"}

Set up the Convex side and the WorkOS dashboard as [Convex's AuthKit guide](https://docs.convex.dev/auth/authkit) describes, with `http://localhost:3000/callback` as the redirect URI. Put the client ID in `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-convex-module'],
  // Set through NUXT_PUBLIC_WORKOS_CLIENT_ID.
  runtimeConfig: { public: { workosClientId: '' } },
})
```

Create the AuthKit client in a client-only plugin. It handles the redirect back from WorkOS and restores the session:

```ts [app/plugins/workos.client.ts]
import { createClient, type User } from '@workos-inc/authkit-js'

export default defineNuxtPlugin(async () => {
  const user = useState<User | null>('workos:user', () => null)
  const isLoading = useState('workos:loading', () => true)

  const authkit = await createClient(useRuntimeConfig().public.workosClientId, {
    redirectUri: `${window.location.origin}/callback`,
    onRefresh: (response) => {
      user.value = response.user
    },
  })
  user.value = authkit.getUser()
  isLoading.value = false

  return { provide: { authkit } }
})
```

Then hand the session to the Convex client in `app.vue`, as the React adapter does:

```vue [app.vue]
<script setup lang="ts">
import type { User } from '@workos-inc/authkit-js'

const user = useState<User | null>('workos:user', () => null)
const isLoading = useState('workos:loading', () => true)
const nuxtApp = useNuxtApp()

provideConvexWithAuth({
  client: useConvex()!,
  useAuth: () => ({
    isLoading,
    isAuthenticated: computed(() => !!user.value),
    fetchAccessToken: async () => {
      try {
        return await nuxtApp.$authkit.getAccessToken()
      }
      catch {
        return null
      }
    },
  }),
})
</script>

<template>
  <NuxtPage />
</template>
```

Every component below now has [`useConvexAuth()`](/guide/auth-state) and the `<Authenticated>` components. Sign in and out with the AuthKit client:

```vue [pages/index.vue]
<script setup lang="ts">
const { $authkit } = useNuxtApp()
</script>

<template>
  <Authenticated>
    <button @click="$authkit.signOut()">Sign out</button>
  </Authenticated>
  <Unauthenticated>
    <button @click="$authkit.signIn()">Sign in</button>
  </Unauthenticated>
</template>
```

During a server render the session is not known yet, so the auth state reads as loading until the plugin has run in the browser.
