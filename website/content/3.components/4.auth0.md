A Vue port of `convex/react-auth0`: a thin shim that adapts [Auth0](https://auth0.com)'s `useAuth0()` into the provider-agnostic [Convex auth state](/guide/auth-state). No new auth core — just the SDK adapter.

:upstream-baseline{source="convex" entry="convex/react-auth0"}

## Install

::code-group

```bash [pnpm]
pnpm add @auth0/auth0-vue
```

```bash [npm]
npm i @auth0/auth0-vue
```

```bash [yarn]
yarn add @auth0/auth0-vue
```

```bash [bun]
bun add @auth0/auth0-vue
```

::

The adapter auto-enables on the next dev run.

## Configure

Register `@auth0/auth0-vue`'s plugin as Auth0 documents, then set `convex.auth0: false` in `nuxt.config.ts` only if you want to force the adapter off. Nothing else is required on the Nuxt side.

Convex-side setup (the Auth0 provider entry in `auth.config.ts`) is unchanged from [Convex's Auth0 guide](https://docs.convex.dev/auth/auth0).

## Use

Call the composable in a top-level component, inside an app wrapped by the configured Auth0 plugin:

```vue [app.vue]
<script setup lang="ts">
// A Vue port of `<ConvexProviderWithAuth0>`.
provideConvexAuthFromAuth0()
</script>

<template>
  <Authenticated>Signed in with Auth0</Authenticated>
  <Unauthenticated>Sign in</Unauthenticated>
</template>
```

The adapter reads Auth0's `useAuth0()` and authenticates Convex with the Auth0 `id_token`.

### `<ConvexProviderWithAuth0>`

The drop-in component form:

```vue [app.vue]
<template>
  <ConvexProviderWithAuth0>
    <NuxtPage />
  </ConvexProviderWithAuth0>
</template>
```

| Prop | Type | Default | Purpose |
| --- | --- | --- | --- |
| `client` | `IConvexVueClient` | the injected client | Override the Convex client the auth state is wired into. |
