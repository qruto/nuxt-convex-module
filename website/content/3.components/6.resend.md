[`@convex-dev/resend`](https://github.com/get-convex/resend) sends email through [Resend](https://resend.com) with durable queuing, batching, and retries. It is a **server-only Convex component**: its whole surface lives inside your Convex deployment, and it has no React integration — so there is nothing to port, and nothing to install on the Nuxt side.

::tip
Nothing to enable. Unlike the other entries in this section, there is no auto-detection, no module option, and no subpath export — because there is no client-side code.
::

## Install

Add it to your Convex deployment, following [its own README](https://github.com/get-convex/resend):

::code-group

```bash [pnpm]
pnpm add @convex-dev/resend
```

```bash [npm]
npm i @convex-dev/resend
```

```bash [yarn]
yarn add @convex-dev/resend
```

```bash [bun]
bun add @convex-dev/resend
```

::

```ts [convex/convex.config.ts]
import { defineApp } from 'convex/server'
import resend from '@convex-dev/resend/convex.config.js'

const app = defineApp()
app.use(resend)
export default app
```

Set `RESEND_API_KEY` in your Convex deployment's environment (`npx convex env set`), not in your Nuxt `.env` — the key must never reach the browser.

## Use

Wrap the component in your own Convex function, then call that function from Vue with the ordinary composables:

```ts [convex/email.ts]
import { Resend } from '@convex-dev/resend'
import { components } from '#convex/api'
import { mutation } from '#convex/server'
import { v } from 'convex/values'

export const resend: Resend = new Resend(components.resend, {})

export const sendWelcome = mutation({
  args: { to: v.string() },
  handler: async (ctx, { to }) => {
    await resend.sendEmail(ctx, {
      from: 'hello@example.com',
      to,
      subject: 'Welcome',
      html: '<p>Glad you are here.</p>',
    })
  },
})
```

```vue [components/WelcomeButton.vue]
<script setup lang="ts">
import { api } from '#convex/api'

const sendWelcome = useMutation(api.email.sendWelcome)
</script>

<template>
  <button @click="sendWelcome({ to: 'someone@example.com' })">
    Send welcome email
  </button>
</template>
```

That is the whole integration. `useMutation` and `useAction` are documented under [mutations & actions](/guide/mutations-and-actions); the delivery status the component tracks is an ordinary Convex table, so a [`useQuery`](/guide/queries) subscription streams it live.

## Other server-only components

The same pattern covers every Convex component with no client surface — reach for `useMutation` / `useAction` to invoke, and `useQuery` to watch whatever it records. Browse them at [convex.dev/components](https://www.convex.dev/components).
