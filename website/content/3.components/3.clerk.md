A Vue port of `convex/react-clerk`: a thin shim that adapts [Clerk](https://clerk.com)'s `useAuth()` into the provider-agnostic [Convex auth state](/guide/auth-state). No new auth core — just the SDK adapter.

## Install

::code-group

```bash [pnpm]
pnpm add @clerk/vue
```

```bash [npm]
npm i @clerk/vue
```

```bash [yarn]
yarn add @clerk/vue
```

```bash [bun]
bun add @clerk/vue
```

::

The adapter auto-enables on the next dev run.

## Configure

Set up `@clerk/vue`'s own plugin as Clerk documents, then set `convex.clerk: false` in `nuxt.config.ts` only if you want to force the adapter off. Nothing else is required on the Nuxt side.

Convex-side setup (the JWT template and the Clerk provider entry in `auth.config.ts`) is unchanged from [Convex's Clerk guide](https://docs.convex.dev/auth/clerk).

## Use

Call the composable in a top-level component, above anything that reads Convex data:

```vue [app.vue]
<script setup lang="ts">
// A Vue port of `<ConvexProviderWithClerk>`.
provideConvexAuthFromClerk()
</script>

<template>
  <Authenticated>Signed in with Clerk</Authenticated>
  <Unauthenticated>Sign in</Unauthenticated>
</template>
```

The adapter reads Clerk's `useAuth()`. When Clerk's native Convex integration is active (the session token's `aud` claim is `convex`), it fetches the session token directly; otherwise it falls back to the `convex` JWT template. Either way the token is re-fetched when the active organization *or* the user's org role changes.

### `<ConvexProviderWithClerk>`

The drop-in component form, for when a wrapper reads better than a setup call:

```vue [app.vue]
<template>
  <ConvexProviderWithClerk>
    <NuxtPage />
  </ConvexProviderWithClerk>
</template>
```

| Prop | Type | Default | Purpose |
| --- | --- | --- | --- |
| `client` | `IConvexVueClient` | the injected client | Override the Convex client the auth state is wired into. |
| `use-auth` | `UseAuth` | `@clerk/vue`'s `useAuth` | Override the Clerk composable the adapter reads — useful in tests. |

Both props are optional here; upstream's React component requires `useAuth`.
