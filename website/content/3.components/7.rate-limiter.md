`useRateLimit` reads a rate limit from your Convex deployment and tells a component whether an action is allowed now, and when it can be retried. Use it to disable a button before the server would refuse the request. It is a Vue port of `@convex-dev/rate-limiter/react`. The limits themselves are enforced in your Convex functions.

:upstream-baseline{source="rate-limiter"}

## Install

:pm-install{packages="@convex-dev/rate-limiter@~0.4.0"}

`useRateLimit` is auto-imported on the next dev run.

## Configure

Set up the component as [its guide](https://www.convex.dev/components/rate-limiter) describes: `app.use(rateLimiter)` in `convex.config.ts` and a `RateLimiter` with your limits. Then export the two functions the composable reads:

```ts [convex/example.ts]
export const { getRateLimit, getServerTime } = rateLimiter.hookAPI('sendMessage', {
  key: async ctx => await getUserId(ctx),
})
```

## Use

```vue [components/SendButton.vue]
<script setup lang="ts">
import { api } from '~~/convex/_generated/api'

const { status } = useRateLimit(api.example.getRateLimit, {
  // Syncs the browser's clock with the server's.
  getServerTimeMutation: api.example.getServerTime,
  // How many tokens the action takes.
  count: 1,
})
</script>

<template>
  <button :disabled="status?.ok === false">Send</button>
  <p v-if="status?.ok === false">
    Try again at {{ new Date(status.retryAt).toLocaleTimeString() }}.
  </p>
</template>
```

`status` is a ref: `undefined` while the limit loads, then `{ ok: true }` or `{ ok: false, retryAt }`, with `retryAt` in the browser's time. When `retryAt` passes, it turns back to `{ ok: true }` without a new query.

The options can be a value, a ref or a getter, so a changed `key` or `count` reads the new limit. `check(ts?, count?)` returns the limit's value at a given time, for a count other than the one in the options.

| Option | Type | Purpose |
| --- | --- | --- |
| `getServerTimeMutation` | function reference | The `getServerTime` mutation. Without it, the browser's clock is trusted. |
| `count` | `number` | Tokens the action takes. Default `1`. |
| `name` | `string` | A limit other than the one named in `hookAPI`. |
| `key` | `string` | The key, when `hookAPI` takes it from the client. |
| `sampleShards` | `number` | Shards to sample for a sharded limit. |
| `config` | rate limit config | A one-off limit that is not named in the `RateLimiter`. |
