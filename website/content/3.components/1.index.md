Core Convex is always on. Everything in this section is **opt-in**: install the package and the integration wires itself up on the next dev run — no extra `modules` entries, no configuration.

Each one is a port with the **same public API** as its upstream React/Next counterpart, adapted to Vue. Convex's own docs and examples translate line for line.

## Supported packages

| Package | What you get | Enable | Subpath | Baseline |
|---|---|---|---|---|
| [Better Auth](/components/better-auth) — `@convex-dev/better-auth` | `useAuth`, `/api/auth/**` proxy, SSR prefetch, `auth` middleware, `<AuthBoundary>`, `convexAuth` | `@convex-dev/better-auth` | `/better-auth/vue`, `/better-auth/server` | `0.12` |
| [Clerk](/components/clerk) — `convex/react-clerk` | `provideConvexAuthFromClerk` · `<ConvexProviderWithClerk>` | `@clerk/vue` | `/clerk/vue` | `1.42` |
| [Auth0](/components/auth0) — `convex/react-auth0` | `provideConvexAuthFromAuth0` · `<ConvexProviderWithAuth0>` | `@auth0/auth0-vue` | `/auth0/vue` | `1.42` |
| [Polar](/components/polar) — `@convex-dev/polar` | Billing — `<CheckoutLink>` · `<CustomerPortalLink>` | `@convex-dev/polar` | `/polar/vue` | `0.9` |
| [Resend](/components/resend) — `@convex-dev/resend` | Server-only — call it with `useMutation` / `useAction` | — | — | — |

Subpaths are `nuxt-convex-module/<subpath>`. `/clerk/vue`, `/auth0/vue`, and `/polar/vue` are self-contained, so they also work in a [plain Vue](/guide/plain-vue) app; `/better-auth/vue` and `/better-auth/server` rely on Nuxt-provided aliases and runtime config.

The authoritative file-by-file map and pinned upstream baselines live in [`PARITY.md`](https://github.com/qruto/nuxt-convex-module/blob/main/PARITY.md).

## Installing

You only ever add **one** module. Install the package you want and it lights up:

::code-group

```bash [pnpm]
pnpm add @convex-dev/better-auth better-auth   # Better Auth
pnpm add @clerk/vue                            # Clerk
pnpm add @auth0/auth0-vue                      # Auth0
pnpm add @convex-dev/polar @polar-sh/checkout  # Polar billing
```

```bash [npm]
npm i @convex-dev/better-auth better-auth   # Better Auth
npm i @clerk/vue                            # Clerk
npm i @auth0/auth0-vue                      # Auth0
npm i @convex-dev/polar @polar-sh/checkout  # Polar billing
```

```bash [yarn]
yarn add @convex-dev/better-auth better-auth   # Better Auth
yarn add @clerk/vue                            # Clerk
yarn add @auth0/auth0-vue                      # Auth0
yarn add @convex-dev/polar @polar-sh/checkout  # Polar billing
```

```bash [bun]
bun add @convex-dev/better-auth better-auth   # Better Auth
bun add @clerk/vue                            # Clerk
bun add @auth0/auth0-vue                      # Auth0
bun add @convex-dev/polar @polar-sh/checkout  # Polar billing
```

::

Your `modules` array never grows — the integration is detected from the installed package:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-convex-module'],
})
```

Auto-detection is the default, not a requirement. Force one on or off — or point Better Auth at your own auth client — through the `convex` key:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-convex-module'],

  convex: {
    // betterAuth: false,
    // betterAuth: { authClient: './app/convex-auth-client' },
    // clerk: false,
    // auth0: false,
    // polar: false,
    // authRoute: '/api/auth',
  },
})
```

Full option reference: [configuration](/getting-started/configuration#module-options-convex).

## Using none of them

Pure Convex with no auth and no billing? Install none of these — you get just the data layer, the module provides a base client on its own, and nothing drags an auth provider or Polar into your bundle.

::callout{icon="i-lucide-server"}
**Server-only Convex components** have no client integration to port. Install them in your Convex deployment and call their functions from Vue with the ordinary `useMutation` / `useAction` composables — [Resend](/components/resend) is the worked example.
::
