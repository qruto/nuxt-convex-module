`useStream` shows text that is being written, such as an AI reply. The browser that started the stream reads it over HTTP as it arrives. Every other browser, and the same one after a reload, reads it from Convex, where the component stores it in sentences. It is a Vue port of `@convex-dev/persistent-text-streaming`.

:upstream-baseline{source="persistent-text-streaming"}

## Install

:pm-install{packages="@convex-dev/persistent-text-streaming@~0.3.0"}

`useStream` is auto-imported on the next dev run.

## Configure

Set up the component as [its guide](https://www.convex.dev/components/persistent-text-streaming) describes: `app.use(persistentTextStreaming)` in `convex.config.ts`, a query that returns `getStreamBody`, and an HTTP action at `/chat-stream` that writes the stream.

## Use

```vue [components/ChatMessage.vue]
<script setup lang="ts">
import type { StreamId } from '@convex-dev/persistent-text-streaming'
import { api } from '~~/convex/_generated/api'

const props = defineProps<{ streamId: string, driven: boolean }>()
const { siteUrl } = useRuntimeConfig().public.convex

const stream = useStream(
  api.chat.getChatBody,
  new URL(`${siteUrl}/chat-stream`),
  // True in the browser that created the message.
  () => props.driven,
  () => props.streamId as StreamId,
)
</script>

<template>
  <p>{{ stream.text }}</p>
  <p v-if="stream.status === 'error'">The reply could not be finished.</p>
</template>
```

`stream` is a ref of `{ text, status }`, where `status` is `pending`, `streaming`, `done` or `error`. `driven` and `streamId` can be values, refs or getters. A new `streamId` resets the text and starts the next stream.

Pass `{ authToken, headers }` as a fifth argument to authenticate the HTTP request. The options are read when a stream starts, so a refreshed token does not interrupt the stream that is running. This follows the package's Svelte entry. Its React hook restarts on new options and stops the text after the first chunks.

The request is only sent in the browser, never during server rendering.
