`useUploadFile` uploads a file from the browser to a [Cloudflare R2](https://developers.cloudflare.com/r2/) bucket: it asks your Convex deployment for a signed URL, sends the file there with progress, and stores the file's metadata in Convex. It is a port of `@convex-dev/r2/vue` on this module's own client. The package's own Vue entry needs the community `convex-vue` client instead.

For files in Convex's own storage, use [`useUpload`](/guide/file-storage).

:upstream-baseline{source="r2"}

## Install

:pm-install{packages="@convex-dev/r2@~0.10.0"}

`useUploadFile` is auto-imported on the next dev run.

## Configure

Set up the component and the bucket's credentials as [its guide](https://www.convex.dev/components/cloudflare-r2) describes. Then export the two functions the composable calls:

```ts [convex/example.ts]
import { R2 } from '@convex-dev/r2'
import { components } from './_generated/api'
import type { DataModel } from './_generated/dataModel'

export const r2 = new R2(components.r2)

export const { generateUploadUrl, syncMetadata } = r2.clientApi<DataModel>({
  checkUpload: async (ctx, bucket) => {
    // Check here that the user may upload.
  },
})
```

## Use

```vue [components/ImageUpload.vue]
<script setup lang="ts">
import { api } from '~~/convex/_generated/api'

const uploadFile = useUploadFile(api.example)
const progress = ref(0)

async function onChange(event: Event) {
  const file = (event.target as HTMLInputElement).files?.[0]
  if (!file) return
  const key = await uploadFile(file, {
    onProgress: ({ loaded, total }) => (progress.value = loaded / total),
  })
  console.log('Uploaded as', key)
}
</script>

<template>
  <input type="file" accept="image/*" @change="onChange">
  <progress :value="progress" />
</template>
```

`uploadFile(file, { onProgress })` resolves to the object's key once the file is in the bucket and its metadata is in Convex. It rejects when the upload fails.
