`usePresence` keeps a live list of the users in a room: who is online, and when the others were last seen. It sends heartbeats while the page is open and disconnects the user when the tab is hidden or closed. `<FacePile>` shows the list as avatars. Both are Vue ports of `@convex-dev/presence`'s React client.

:upstream-baseline{source="presence"}

## Install

:pm-install{packages="@convex-dev/presence@~0.4.0"}

`usePresence` and `<FacePile>` are auto-imported on the next dev run.

## Configure

Set up the Convex side as [the component's guide](https://www.convex.dev/components/presence) describes: `app.use(presence)` in `convex.config.ts`, and a module that exports `heartbeat`, `list` and `disconnect`:

```ts [convex/presence.ts]
import { Presence } from '@convex-dev/presence'
import { v } from 'convex/values'
import { components } from './_generated/api'
import { mutation, query } from './_generated/server'

export const presence = new Presence(components.presence)

export const heartbeat = mutation({
  args: { roomId: v.string(), userId: v.string(), sessionId: v.string(), interval: v.number() },
  handler: async (ctx, { roomId, userId, sessionId, interval }) => {
    // Check here that the user may join the room.
    return await presence.heartbeat(ctx, roomId, userId, sessionId, interval)
  },
})

export const list = query({
  args: { roomToken: v.string() },
  handler: async (ctx, { roomToken }) => await presence.list(ctx, roomToken),
})

export const disconnect = mutation({
  args: { sessionToken: v.string() },
  // Called over HTTP when the tab closes, so it cannot check auth.
  handler: async (ctx, { sessionToken }) => await presence.disconnect(ctx, sessionToken),
})
```

## Use

```vue [components/Room.vue]
<script setup lang="ts">
import { api } from '~~/convex/_generated/api'

const props = defineProps<{ roomId: string, name: string }>()
const presenceState = usePresence(api.presence, () => props.roomId, () => props.name)
</script>

<template>
  <FacePile :presence-state="presenceState ?? []" />
</template>
```

`usePresence(presence, roomId, userId, interval?, convexUrl?)` returns a ref of the room's users, the current user first, or `undefined` until the first heartbeat answers. The room and the user can be a value, a ref or a getter: a change leaves the old room and joins the new one. `interval` is the time between heartbeats, 10 seconds by default.

`<FacePile>` shows the first five users and a drop-down with the rest. It uses the package's own stylesheet. For your own design, render the list from `usePresence` yourself.

When the tab closes, the composable disconnects through the `disconnect` function you pass, wherever it lives. Upstream's React hook always calls `presence:disconnect`, so with React the functions must sit in `convex/presence.ts`.

`@convex-dev/presence` lists React as a peer, so npm and pnpm install it next to Vue. Nothing from React reaches your bundle.
