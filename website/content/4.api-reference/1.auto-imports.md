Everything below is auto-imported in pages, components, and composables. Ten composables also carry a `useConvex*` alias, for apps where the bare name clashes: `useConvexQuery`, `useConvexQueries`, `useConvexMutation`, `useConvexAction`, `useConvexPaginatedQuery`, `useConvexAsyncQuery`, `useConvexAsyncPaginatedQuery`, `useConvexUpload`, `useConvexUploadQueue`, `useConvexStorageUrl`. With [`convex.autoImports: 'prefixed'`](/getting-started/configuration#module-options-convex) every name below is injected with `Convex` in it instead (`<ConvexAuthenticated>`, `useConvexPreloadedQuery`), and with `false` none; every name stays importable from its [subpath export](/api-reference#subpath-exports).

For what runs in Nitro server code instead, see [server auto-imports](/api-reference/server-imports).

## Data

| Name | Description |
|---|---|
| `useQuery` / `useQuery_experimental` | [Reactive live query](/guide/queries) (throwing / result-union). |
| `useQueries` | [A dynamic number of live queries](/guide/queries#usequeries) from one composable call. |
| `useMutation` | [Call a Convex mutation](/guide/mutations-and-actions) (supports optimistic updates). |
| `useAction` | [Call a Convex action](/guide/mutations-and-actions#useaction). |
| `usePaginatedQuery` / `usePaginatedQuery_experimental` | [Cursor pagination](/guide/pagination). |
| `useAsyncQuery` | [SSR-fetched, payload-hydrated live query](/guide/server-and-ssr#useasyncquery-ssr-data-the-nuxt-way) with Nuxt's `{ data, error, status, refresh }` shape. Nuxt-only; explicit imports and its types come from `nuxt-convex-module/app`. |
| `useAsyncPaginatedQuery` | [SSR-fetched first page, then live pagination](/guide/pagination#useasyncpaginatedquery-ssr-first-page) — `usePaginatedQuery`'s fields plus `error` and `refresh`. Nuxt-only, from `nuxt-convex-module/app`. |
| `usePreloadedQuery` | [Hydrate a query preloaded on the server](/guide/server-and-ssr#preloading-for-ssr) with `preloadQuery`. |
| `useConvexConnectionState` | [Live WebSocket connection status](/guide/connection-state). |
| `useConvex` | The underlying `ConvexVueClient`. |

## Types

| Name | Description |
|---|---|
| `AsyncQueryReturn` / `AsyncQueryOptions` / `AsyncQueryStatus` / `AsyncQueryData` | `useAsyncQuery`'s return, options, status union and awaited result — type-only, so `import type { AsyncQueryReturn } from '#imports'` works. Every other public type is imported from a [subpath](/guide/plain-vue#providing-the-client). |
| `AsyncPaginatedQueryReturn` / `AsyncPaginatedQueryOptions` / `AsyncPaginatedQueryData` | The same three for `useAsyncPaginatedQuery`. |

Full signatures live in the generated reference: [client](/api-reference/reference/client) covers the core composables and components, [app](/api-reference/reference/app) the Nuxt-only `useAsyncQuery`, with per-integration modules under [better-auth/client](/api-reference/reference/better-auth/client), [clerk/client](/api-reference/reference/clerk/client), [auth0/client](/api-reference/reference/auth0/client), and [polar/client](/api-reference/reference/polar/client) — see [all modules](/api-reference/reference).
